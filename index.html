Urutan buku belum tersimpan ke database

Kolom sort_order belum ada di tabel flipbooks, sehingga urutan hanya tersimpan di browser ini dan tidak terlihat oleh pengunjung/perangkat lain. Jalankan SQL berikut di Supabase (SQL Editor), lalu muat ulang halaman ini:

alter table public.flipbooks add column if not exists sort_order integer;

update public.flipbooks f
set sort_order = r.rn - 1
from (
  select id, row_number() over (order by created_at desc) as rn
  from public.flipbooks
) r
where f.id = r.id;

notify pgrst, 'reload schema';
